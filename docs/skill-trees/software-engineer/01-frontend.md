# 前端工程師

以下整理資深前端工程師（Senior Front-end Engineer）常見的職缺要求，可對照自己目前的能力，找出需要加強的項目。

## 資深前端工程師

### 核心技術

- **前端基礎**
  - 精通 HTML5、CSS3 與 JavaScript（ES6 以上）
  - 熟悉 TypeScript
  - 熟悉模組化開發、響應式設計（RWD），以及跨裝置、跨瀏覽器的相容性處理
- **框架與生態系**
  - 具備 4 年以上前端開發經驗，能獨立開發並主導專案
  - 熟悉至少一種主流框架，以 React 生態系（Hooks、Context、Router）最為常見，並具備大型專案開發經驗
- **建構工具**
  - 熟悉 Webpack、Vite、Rollup 等建構工具
  - 具備 CI/CD 使用經驗
- **版本控制與協作**
  - 熟悉 Git（以 GitHub Flow 為佳），具備多人協作經驗
  - 具備 Code Review 的習慣

### 程式碼品質與架構

- 重視程式碼品質與可維護性，能撰寫清楚易讀的程式碼
- 能規劃與重構前端架構，提升可維護性與擴展性
- 能進行效能優化，改善使用者的互動體驗
- 能與設計師合作，持續改善產品的 UI/UX

### 溝通與協作

- 具備良好的溝通能力與團隊合作精神
- 能主動釐清需求，將問題轉化為具體的技術方案
- 願意分享經驗，協助團隊成員提升技術能力

## 加分條件

- **UI 框架**：熟悉 Tailwind CSS、MUI、Ant Design 等任一 UI 框架
- **自動化測試**：具備 Jest、Testing Library、Cypress 等前端測試經驗
- **API 協作**：具備前後端串接經驗，能參與 API 規格的制定
- **網站優化**：具備 SEO、Google Analytics、Google Tag Manager 或 Lighthouse 效能優化經驗
- **雲端與部署**：熟悉雲端環境，具備 Vercel、Netlify 等前端部署經驗
- **元件設計**：具備在既有產品中導入元件設計模式、提升 UI 開發效率的經驗
