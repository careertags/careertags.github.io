# 學習資源

CareerTags 學習資源整理職涯發展所需的參考資料，協助你規劃學習方向、了解目標職位的能力要求。

## 內容分類

### [推薦清單](/resources/official-lists)

依主題整理的推薦閱讀清單，目前收錄名人推薦書單，例如比爾蓋茲的年度選書。

### [職涯技能樹](/resources/skill-trees)

整理各職位在不同資歷階段的能力要求，包含核心技能、加分條件與軟實力，可作為學習規劃與求職準備的參考。

## 搭配 CareerTags 使用

在 [CareerTags Chrome 擴充功能](https://chromewebstore.google.com/detail/careertags/hgbdlhjfbbklmcibbnecaoijkhmaeeop?hl=zh-tw)中，你可以選擇職涯目標與目標職位，查看技能缺口，並取得對應主題的精選影片與 Podcast，每則皆附重點摘要與行動計劃。
