# 學習資源

這裡整理職涯規劃用得到的參考資料：值得一讀的推薦清單，以及各職位在不同資歷階段的能力要求。

## 內容分類

### [推薦清單](/resources/official-lists)

依主題整理的推薦閱讀清單，目前收錄名人推薦書單，例如比爾蓋茲的年度選書。

### [職涯技能樹](/resources/skill-trees)

整理各職位在不同資歷階段的能力要求，包含核心技能、加分條件與軟實力，可作為學習規劃與求職準備的參考。

## 在 CareerTags 中學習與練習

CareerTags 的 12 大主題、360 則精選影片與 Podcast，每則附中文重點摘要、精華內容與行動計劃，收錄在 App 與 [Chrome 擴充功能](https://chromewebstore.google.com/detail/careertags/hgbdlhjfbbklmcibbnecaoijkhmaeeop?hl=zh-tw)中。選擇目標職位後，可以查看技能缺口、取得對應的推薦內容，再透過排定練習、實踐日誌與職場故事，把學到的方法用在工作上。詳見[關於我們](/about)。
